## Project Overview

CN SkatePark was founded in 2026 to give young and aspiring skaters a safe alternative to skating on the streets. The long-term vision is to open branches across South Africa and become the national standard for safe skating.

This website presents the business, its services, and ways to get in touch. Part 3 of the project adds JavaScript interactivity, dynamic content, form validation, search engine optimisation (SEO) and public deployment.

**Technologies used:** HTML5, CSS3, JavaScript (ES6), Leaflet.js, OpenStreetMap, Formspree, Git and GitHub, Netlify.

## Features Added in Part 3

### JavaScript Interactivity (2.1)

- **Accordion:** the FAQ on the enquiries page expands and collapses answers.
- **Interactive map:** the About page uses a Leaflet map with OpenStreetMap tiles and a marker with a popup for each location.
- **Animations and transitions:** CSS transitions on buttons, navigation links and the collapsible form, plus scroll-triggered fade-in animations on the home page using the `IntersectionObserver` API.
- **DOM manipulation:** page content, the services table, the form error messages and the email preview are created and updated through JavaScript.
- **Lightbox gallery:** clicking a gallery image on the services page opens a larger view.
- **Collapsible contact form:** the contact form is folded by default and opens with a button (`max-height` transition, with `aria-expanded` updated for accessibility).

### Dynamic Content (2.2)

- The services table is generated by JavaScript rather than hard-coded in the HTML.
- A search box filters the services, and the table can be sorted by column.

### Forms and Validation (4)

- **Contact form (`contact.html`):** collects full name, email, phone number, message type and message.
  - Client-side validation with JavaScript (name length, email format, South African phone number format, message length 10-500 characters).
  - Error messages are shown beside each invalid field.
  - Once valid, the data is compiled into an email (recipient, subject and body) shown as a preview, and the user sends it with a `mailto:` link to the recipient set in the code.
- **Enquiry form (`enquiries.html`):** validated with HTML5 attributes and JavaScript, submitted asynchronously (AJAX using `fetch`) so the page does not reload, and followed by an on-page response about cost or availability. [CONFIRM THIS MATCHES YOUR FINAL CODE]

## SEO Strategy

### On-Page SEO

- **Keyword research:** target keywords include *skatepark Pretoria*, *skateboarding lessons Pretoria*, *safe skating South Africa* and *contact CN SkatePark*. Keywords were identified using Google autocomplete and "People also ask" suggestions and are used in titles, headings, body text and alt text.
- **Title tags and meta descriptions:** every page has its own unique title and description.
- **Header tags:** each page has one `<h1>`, with `<h2>` and `<h3>` used for sections in order.
- **Image optimisation:** images have descriptive lower-case file names with hyphens and meaningful `alt` text, and are compressed. Images below the fold use `loading="lazy"`.
- **URL structure:** short, lower-case, descriptive page names (`about.html`, `services.html`, `contact.html`).
- **Internal linking:** the navigation appears in the header and footer, and body text links to related pages.
- **Mobile-friendliness:** responsive layout with a viewport meta tag and media queries for tablet (481-768px) and smartphone (480px and below).

### Off-Page SEO (Strategy)

- **Backlinks:** approach local skate shops, Pretoria sports and youth organisations, schools and local business directories to link to the website.
- **Social media:** promote trick clips and events on Instagram, TikTok and YouTube (`@cnSkatePark`), with the website link in each profile and a post for every event.
- **Local SEO:** create a Google Business Profile, keep the business name, address and phone number consistent everywhere, include "Pretoria" in titles and content, and use local business structured data (JSON-LD) on the contact page.

### Technical SEO

- `robots.txt` tells crawlers which paths to skip and points to the sitemap.
- `sitemap.xml` lists all five pages with their last modified date and priority.

## Security and Performance

**Security**

- User input is displayed with `textContent`, never `innerHTML`, to prevent cross-site scripting (XSS).
- Client-side validation checks all form fields, and the README notes that a production system would also validate on the server.
- The site is served over HTTPS by Netlify.
- External links that open in a new tab use `rel="noopener noreferrer"`.
